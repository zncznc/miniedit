# EverEdit 复刻计划

目标：把 `D:\REA\everedit-ref`（EverEdit 4.x 完整安装目录）里的功能面，在 MiniEdit 上逐块复刻。
"复刻"的判据不是长得像，而是**命令能对上**：原版菜单里有这一项，按原版快捷键能触发，行为一致。

## 一、对方有多少东西（可数）

## 二、我们现在的样子

`index.html` 一共 116 行：7 个图标按钮、2 个下拉、一条查找栏、一条状态栏、3 个对话框。

已有的能力（能用的）：多标签、语法高亮、代码折叠、查找/替换（非正则之外的简单形式）、
6 种编码读写、主题切换、崩溃恢复快照、文件关联与拖放。

**131 条命令里注册了 0 条**——现在所有操作都硬编码在按钮上，没有命令层，这是第一步要补的。

## 三、分批

每一批都以"能用、能验证"结束，不追求一次铺满。批次之间可单独发版。

### P0 · 命令层与菜单（地基）· 已交付 1.5.0
- 命令注册表 `js/commands.mjs`：一条命令 = `{ id, 名称, 快捷键, 可用条件, 执行 }`
- 菜单栏：11 个主菜单、49 个子菜单，**文本与层级直接来自 `2052.lng`**，不手抄
- 快捷键分发：按 `key.ini` 原表映射，`C+K,C+1` 这类双段组合也要支持
- 撤销/重做历史栈（现在 textarea 的 undo 撑不起批量命令）
- 先落 60~70 条纯文本命令：大小写、对齐、排序/去重、缩进、注释、删除类、选择类、移动类、折叠级别
- 验收：`node tools/ee-audit.mjs` 覆盖率从 0% 涨到 50%+；每条命令有快捷键且与原版一致
- **实际交付**：74/131 = 56.5%（`js/commands.mjs`），8 个主菜单；`tools/cmd-test.mjs` 33 项断言全过；
  自检新增 `menu` 与 `cmd` 两步，安装目录版 8 步全 ok

### P1 · 查找替换做透（原版的重头）
- 独立"查找/替换"对话框（原版两个是分开的 `DLG`）
- 正则、区分大小写、全词、循环、选区内外、方向、转义序列
- 查找全部结果列表、在文件夹中查找（`cm_find_infiles`）、增量查找
- 替换：单个/全部/选区、保留大小写、反向引用 `\1`
- 验收：与原版对同一份文本的输出逐字一致

### P2 · 编辑增强
- 列/块选择、列模式粘贴、行尾列模式粘贴、多光标
- 括号匹配跳转与高亮（`cm_move_brace`）
- 自动缩进、Tab/空格互转、格式化
- 代码片段（`snippet/`）、新建模板（`template/`）、调用提示（`calltip/*.ecp`）
- 拼写检查（原版有独立词典目录）

### P3 · 文档与侧栏
- 停靠窗格：文件树、大纲、书签管理、片段、打开文件列表（对应 `cm_dock_*` 7 条命令）
- 书签（`cm_marker_*`）、文档地图
- 二进制/十六进制查看（原版外挂 `hexedit.dll`，我们要自己写视图）
- 编码检测与转换（`chardet.dll` 同理，需自研探测）、行尾转换、BOM 处理
- 会话、最近文件、恢复最后关闭的文件
- 打印与打印预览、导出 HTML/RTF

### P4 · 工具类
- 外部工具调用（`bin/ctags.exe`、`diff.exe`、`sort.exe` 可直接复用，它们不依赖原版）
- 排序/去重、Base64 编码解码、AES 加解密、字数统计
- 宏：原版是 VBScript（`macro/`），**没有现成 JS 引擎能直接兼容**，需要自定的 JS 宏 API，或只做动作录制
- 工程管理、多文件搜索替换联动

### P5 · 兼容性收尾
- 键位自定义界面（写回 `key.ini` 格式）
- 设置界面全套（`setting.ini` 有 100+ 项）
- 插件（`plugin/*.dll`）：**原版插件是 32 位 DLL，不能直接加载**，只能用内置能力替代常用插件

## 四、硬骨头（先说明，别指望一次做完）

| 项 | 为什么要命 |
| --- | --- |
| VBScript 宏 | 原版宏是 VBScript + 私有 `Editor` 对象模型。要么内嵌 VBScript 引擎（体积 +20 MB），要么改用 JS 宏并与原版宏不兼容 |
| DLL 插件 | 私有 ABI、32 位，只能重写替代品 |
| `chardet.dll` / `hexedit.dll` | 原生 DLL，不能复用，编码探测与十六进制视图要自己做 |
| 列编辑/多光标 | textarea 撑不住，需要换编辑内核（或叠一层自绘选区） |
